# Contributing

## Branches

- `main`: stable releases only
- `develop`: integration branch
- `task/NN-short-name`: one branch per task (for example, `task/04-repo-init`)
- `feature/short-name`: feature work inside a task
- `fix/short-name`: bug fixes

## Commit messages

Format: `type: short summary`

Types: `feat`, `fix`, `docs`, `test`, `build`, `ci`, `chore`

Example: `feat: add parcel entry servlet`

## Workflow

1. Branch from `develop`.
2. Commit small, meaningful changes.
3. Open a pull request into `develop`.
4. Merge and keep the branch.
